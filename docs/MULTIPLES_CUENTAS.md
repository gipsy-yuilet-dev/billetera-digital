# 🏦 Sistema de Múltiples Cuentas - Guía Completa

## 🎯 ¿Qué es el Sistema de Múltiples Cuentas?

Ahora puedes tener **varias cuentas** en tu billetera Alke Wallet y **transferir dinero entre ellas**. Es como tener diferentes bolsillos para organizar tu dinero.

---

## 📊 Tipos de Cuentas Disponibles

### 1. 💳 Cuenta Corriente
- Para gastos del día a día
- Color: **Azul**
- Uso recomendado: Compras, pagos, transferencias frecuentes

### 2. 🐷 Cuenta de Ahorro
- Para guardar dinero
- Color: **Verde**
- Uso recomendado: Metas de ahorro, fondo de emergencia

### 3. 📈 Cuenta de Inversión
- Para inversiones y crecimiento
- Color: **Amarillo**
- Uso recomendado: Inversiones, fondos a largo plazo

### 4. 💰 Otra
- Personalizable
- Color: **Gris**
- Uso recomendado: Proyectos específicos, viajes, etc.

---

## 🚀 Cómo Crear una Nueva Cuenta

### Paso 1: Acceder a Mis Cuentas
1. Inicia sesión en tu cuenta
2. Ve al Dashboard
3. Haz clic en el botón **"Mis Cuentas"** (ícono de billetera amarillo)

### Paso 2: Crear Cuenta
1. Haz clic en **"Nueva Cuenta"**
2. Completa el formulario:
   - **Nombre**: Ej: "Ahorro para Vacaciones"
   - **Tipo**: Selecciona el tipo de cuenta
   - **Saldo Inicial**: (Opcional) Puedes agregar $0 o más
3. Haz clic en **"Crear Cuenta"**
4. ✅ ¡Listo! Tu nueva cuenta está creada

**Ejemplo:**
```
Nombre: Fondo de Emergencia
Tipo: Cuenta de Ahorro
Saldo Inicial: $1000.00
```

## 🔄 Cómo Cambiar de Cuenta Activa

Tienes 2 formas de cambiar la cuenta activa:

### Opción 1: Desde el Dashboard
1. En el dashboard verás un **selector desplegable** debajo de tu saldo
2. Haz clic en el selector
3. Elige la cuenta que quieres usar
4. ✅ La página se recargará con la nueva cuenta activa

### Opción 2: Desde Mis Cuentas
1. Ve a **"Mis Cuentas"**
2. Verás todas tus cuentas en tarjetas
3. La cuenta activa tiene un **borde azul** y badge "Activa"
4. En las demás cuentas, haz clic en **"Usar esta cuenta"**
5. ✅ Ahora esa cuenta es la activa

## 💸 Transferir Entre Tus Propias Cuentas

### Paso a Paso:

1. **Ir a Enviar Dinero**
   - Desde el dashboard, haz clic en **"Enviar"**

2. **Activar Modo Transferencia Propia**
   - Marca el checkbox **"Transferir entre mis cuentas"**
   - Aparecerá un selector de cuenta destino

3. **Seleccionar Cuenta Destino**
   - Elige a qué cuenta quieres transferir
   - Verás el saldo actual de cada cuenta

4. **Ingresar Detalles**
   - **Monto**: Cantidad a transferir
   - **Descripción**: Ej: "Ahorro mensual"

5. **Confirmar**
   - Haz clic en **"Enviar Dinero"**
   - ✅ El dinero se transfiere instantáneamente

### Ejemplo Práctico:

```
Cuenta Origen: Cuenta Corriente ($500.00)
Cuenta Destino: Cuenta de Ahorro ($1000.00)
Monto: $200.00
Descripción: Ahorro de enero

RESULTADO:
✅ Cuenta Corriente: $300.00 (-$200)
✅ Cuenta de Ahorro: $1200.00 (+$200)
```

## 📊 Visualizar Transacciones por Cuenta

### En el Dashboard (Tabla DEBE/HABER):
- Cada transacción muestra un **badge gris** con el nombre de la cuenta
- Ejemplo: `Ana P. [Cuenta Corriente]`

### En Historial de Transacciones:
- Todas las transacciones de todas tus cuentas
- Cada una muestra la cuenta asociada
- Puedes ver el flujo completo de dinero

### En Mis Cuentas:
- Cada tarjeta muestra:
  - Nombre de la cuenta
  - Tipo
  - Saldo actual
  - Número de transacciones

## 🎬 Ejemplo Completo de Uso

### Escenario: Organizar tu dinero

**Paso 1: Configuración Inicial**
```
1. Crear "Cuenta Corriente" → $2000 (gastos diarios)
2. Crear "Ahorro Vacaciones" → $0 (meta)
3. Crear "Fondo Emergencia" → $500 (seguridad)
```

**Paso 2: Recibir Salario**
```
1. Activar "Cuenta Corriente"
2. Depositar → $3000 (Salario de enero)
3. Saldo Cuenta Corriente: $5000
```

**Paso 3: Organizar Dinero**
```
Transferencia 1:
- De: Cuenta Corriente
- A: Ahorro Vacaciones
- Monto: $500
- Resultado: Corriente $4500 | Ahorro $500

Transferencia 2:
- De: Cuenta Corriente
- A: Fondo Emergencia
- Monto: $300
- Resultado: Corriente $4200 | Emergencia $800
```

**Paso 4: Gastos del Mes**
```
1. Activar "Cuenta Corriente"
2. Enviar $50 a María (cena)
3. Enviar $100 a Carlos (pago compartido)
4. Resultado: Corriente $4050
```

**Resumen Final:**
```
📊 Cuenta Corriente:    $4050 (Disponible)
🐷 Ahorro Vacaciones:   $500  (Meta)
🚨 Fondo Emergencia:    $800  (Seguridad)
────────────────────────────────
💰 Total:               $5350
```

## ✨ Ventajas del Sistema de Múltiples Cuentas

### 1. 🎯 Organización
- Separa tu dinero por propósitos
- Visualiza fácilmente tus ahorros vs gastos

### 2. 📈 Control Financiero
- Establece límites por cuenta
- Evita gastar el dinero ahorrado

### 3. 🎪 Flexibilidad
- Mueve dinero entre cuentas cuando lo necesites
- Adapta tu estructura financiera

### 4. 📊 Visibilidad
- Ve todas tus cuentas en un solo lugar

### 5. 🔒 Seguridad
- Cada transacción se registra
- Historial completo por cuenta

## ❓ Preguntas Frecuentes

**P: ¿Cuántas cuentas puedo crear?**  
R: No hay límite. Puedes crear todas las que necesites.

**P: ¿Puedo eliminar una cuenta?**  
R: Actualmente no, pero puedes dejar de usarla (transferir todo su saldo a otra).

**P: ¿Las transferencias entre mis cuentas tienen costo?**  
R: No, las transferencias entre tus propias cuentas son 100% gratuitas.

**P: ¿Qué pasa si envío dinero a otro usuario?**  
R: El dinero sale de tu cuenta activa y va a la cuenta activa del destinatario.

**P: ¿Puedo cambiar el nombre de una cuenta?**  
R: Actualmente no, pero puedes crear una nueva con el nombre deseado.

**P: ¿Las transacciones entre mis cuentas aparecen en el historial?**  
R: Sí, aparecen en ambas cuentas (origen y destino) con la etiqueta "(Propia)".

**P: ¿Puedo ver el balance total de todas mis cuentas?**  
R: En "Mis Cuentas" puedes ver todas tus cuentas y sus saldos individuales.

## 💡 Consejos de Uso

### 🎯 Estrategia de Organización:

1. **Cuenta Corriente**: Para gastos diarios (50% del ingreso)
2. **Ahorro**: Para metas a corto plazo (30% del ingreso)
3. **Inversión**: Para el futuro (20% del ingreso)

### 📅 Rutina Recomendada:

**Al recibir dinero:**
1. Deposita en Cuenta Corriente
2. Transfiere a Ahorro (meta del mes)
3. Transfiere a Inversión/Fondo Emergencia

**Durante el mes:**
- Usa solo la Cuenta Corriente para gastos
- No toques las otras cuentas

**Fin de mes:**
- Revisa tus transacciones
- Ajusta transferencias según necesidad
